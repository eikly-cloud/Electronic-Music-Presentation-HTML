# Abstract of Electronic Music

A six-slide, offline-capable web presentation about electronic music, fine arts and music culture.

## Run

Download or clone this repository, then open `dist/index.html` in a modern desktop browser. All fonts, album artwork and animation code are included locally; no build step or internet connection is required.

Use the arrow keys or on-screen navigation to change slides. Slides 3–5 feature a four-second 3D CD archive transition; Escape or the Skip button dismisses it. Reduced-motion preferences are respected.

## Featured tracks

- 驟雨の狭間 / Rainshower — Silentroom — 180 BPM
- SATELLITE — かめりあ — 150 BPM
- Ushio (Emotional Intro Mix) — New World — 139 BPM

## Files

- `dist/`: complete presentation, JavaScript, styles, local fonts and artwork.
- `dist/ASSET-CREDITS.txt`: artwork and design references.
- `dist/covers/sources.json` and `dist/covers/archive-sources.json`: cover source information.
- `dist/RhineLabUI-LICENSE.txt`: license for the referenced RhineLabUI project.
